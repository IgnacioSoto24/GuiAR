# GuiAR - Tutor IA con RAG

Aplicación web que utiliza inteligencia artificial para orientar a estudiantes en la resolución de actividades, usando un enfoque RAG (Retrieval-Augmented Generation) con ejecución local.

---

## ✅ Requisitos

Instalar lo siguiente:

### 1. Python
- Versión: 3.10 o superior  
- Descargar: https://www.python.org/

---

### 2. Ollama 
- Descargar: https://ollama.com/

Verificar instalación:
```bash
ollama --version

---

### 3. Descargar modelo de IA

Ejecuta uno de los siguientes comandos:

```bash
ollama run mistral
ollama run llama3

Verificar instalación:
```bash
ollama list

### 2. Documentos

- se debe subir los documentos a trabajar desde la aplicación directamente
